# V1.5.7 — Anniversaire : carte unique

- Un anniversaire = une seule carte, issue de la date de naissance du profil.
- Le coeur « Féliciter » ajoute/retire la réaction de l'utilisateur et affiche le compteur.
- « Commenter / Lui souhaiter » ajoute un message sous la même carte.
- Les anciens souhaits créés par la V1.5.6 sont repris visuellement comme commentaires afin de ne pas perdre les tests/données existants.
- Le bloc séparé « Messages d'anniversaire » est supprimé.
- Les autres célébrations (bienvenue/réussite) restent inchangées.

Avant déploiement, exécuter :
`supabase/20261001120000_v157_birthday_interactions.sql`
