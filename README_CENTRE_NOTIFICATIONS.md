# Centre de notifications

Cette version ajoute :

- une rubrique Notifications dans le menu ;
- un compteur rouge des notifications non lues ;
- filtres Toutes / Non lues / Messages / Événements / Temps forts / Points ;
- ouverture directe de la rubrique concernée ;
- marquage individuel ou global comme lu ;
- suppression d'une notification ;
- conservation des notifications dans Supabase ;
- notifications temps réel pour les messages, posts, événements, newsletters, sondages et célébrations.

## Supabase obligatoire

Exécuter une fois :

`supabase/notifications_migration.sql`

Aucune table existante n'est supprimée.
