# Thèmes de niveaux — amélioration admin

Le champ « Thème du niveau » reste totalement libre : l’admin peut saisir « Nos valeurs », « Notre histoire », « Nos missions », « Nos entreprises », etc.

Les thèmes déjà utilisés sont désormais mémorisés à partir des jeux existants et reproposés automatiquement dans une liste de suggestions. Aucun thème n’est imposé et aucune migration SQL supplémentaire n’est nécessaire.
