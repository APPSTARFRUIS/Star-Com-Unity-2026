# PlanEat — Étape 4 : moteur de planning personnalisé

Cette étape branche la génération du planning sur les paramètres réellement enregistrés :
- nombre de convives et budget hebdomadaire ;
- régime alimentaire ;
- allergies et intolérances ;
- aliments exclus ;
- équipements disponibles ;
- objectif repas légers ;
- saisonnalité ;
- catalogue de recettes actif, y compris les recettes ajoutées via l'administration.

Le moteur favorise également la mutualisation des ingrédients, limite les répétitions, privilégie les déjeuners rapides et valorise les recettes adaptées au batch cooking tout en conservant la contrainte budgétaire lorsque celle-ci est réalisable.
