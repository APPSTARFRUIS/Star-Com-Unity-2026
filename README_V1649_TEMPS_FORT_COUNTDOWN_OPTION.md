# V1.6.49 — Compte à rebours optionnel

- Lors de la création d’un événement de type **Temps fort**, une case **Afficher un compte à rebours** est proposée.
- Décochée : le Temps fort reste affiché dans « À ne pas manquer », sans compteur.
- Cochée : le compteur cible la date et l’heure de début de l’événement.
- Les anciens Temps forts sans valeur enregistrée gardent leur compte à rebours historique.
- Aucun changement pour les autres types d’événements, Jeux, E-learning ou l’Admin Animations.
