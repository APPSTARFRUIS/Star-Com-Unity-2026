# Star Com'Unity V1.6.21 — Dashboard statistiques Admin

- Nouveau premier onglet `Dashboard` dans Administration.
- Indicateurs agrégés : utilisateurs, interactions, contenus, push actifs, jeux, pronostics, newsletters et notifications.
- Filtres 7 / 30 / 90 jours et actualisation manuelle.
- Répartition des comptes par entité et activité par type sous forme de graphiques légers, sans dépendance supplémentaire.
- Aucun suivi individuel, aucune durée de connexion et aucun classement des salariés.
- Aucun SQL à exécuter : le dashboard exploite les données déjà présentes.
- Les tables optionnelles non disponibles sont ignorées sans bloquer la page.
