# Module Classements & Engagement

## Installation Supabase (une seule fois)

1. Ouvrir Supabase > SQL Editor > New query.
2. Copier le contenu du fichier :
   `supabase/engagement_module_migration.sql`
3. Cliquer sur Run.
4. Redéployer ensuite l'application si nécessaire.

## Fonctionnalités ajoutées

- Classement général basé sur le solde de points actuel.
- Classement mensuel calculé depuis les transactions du mois.
- Top contributeurs automatique : publications, commentaires, idées et réponses aux sondages.
- Animations ponctuelles administrables :
  - compte à rebours ;
  - tirage au sort avec ticket gratuit ou payé en points ;
  - jeu concours ;
  - calendrier de l'Avent ;
  - mission ponctuelle.
- Tirage aléatoire d'un gagnant par un administrateur ou modérateur.

Le nouvel écran est accessible depuis le menu `Classements`.
