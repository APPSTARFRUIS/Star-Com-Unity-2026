# V1.6.35 — Ma Poire : placement direct des accessoires

- Dans Administration > Mascotte > Accessoires, l'aperçu devient interactif.
- Cliquer/toucher puis faire glisser l'accessoire sur la poire met à jour sa position X/Y en temps réel.
- Fonctionne à la souris et au tactile via Pointer Events.
- Les curseurs restent disponibles pour affiner taille, rotation, position et écart d'une paire.
- Pour une paire de chaussures, le déplacement agit désormais sur le centre réel de la paire (X + Y).
- Aucun SQL supplémentaire : les colonnes de positionnement de la V1.6.34 sont réutilisées.
