# V1.5.6 — Correctif « Lui souhaiter »

- Le bouton « Lui souhaiter » n'ouvre plus la fenêtre « Célébrer un événement ».
- Il ouvre une fenêtre dédiée pour écrire un message d'anniversaire au collaborateur concerné.
- Le message est enregistré dans les messages d'anniversaire existants, sans créer une célébration via le formulaire général.
- L'auteur du message est affiché lorsque son profil est disponible.
- Le bouton « Nouvelle célébration » et le reste de l'espace Célébrations ne sont pas modifiés.
- Aucune migration SQL supplémentaire n'est nécessaire.
