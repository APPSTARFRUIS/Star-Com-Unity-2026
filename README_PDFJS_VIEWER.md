# Lecteur PDF intégré

Cette version remplace l'aperçu PDF natif du navigateur par un lecteur basé sur PDF.js.

Fonctions :
- aperçu directement dans Star Com'Unity ;
- navigation page précédente / suivante ;
- zoom ;
- rotation ;
- téléchargement séparé ;
- chargement du PDF uniquement lorsque l'utilisateur clique sur l'œil.

Aucune migration Supabase n'est nécessaire.

PDF.js est chargé dynamiquement depuis le CDN cdnjs au moment de la première ouverture d'un PDF.
