# Multi-entreprises V1

Cette version fait évoluer Star ComUnity vers Star Group.

Entreprises intégrées :
Star Fruits, Star Export, Star PMP, AC Fruit, Eurostème.

Adapté :
- Équipe / annuaire : filtre Groupe ou entreprise.
- Organigramme : vue Groupe ou vue entreprise.
- Documents : audience Tout Star Group ou entreprise.
- Sondages : audience Tout Star Group ou entreprise.
- Événements : audience Tout Star Group ou entreprise.

Les Jeux restent volontairement globaux pour tous les salariés.

Les contenus historiques restent Star Fruits par défaut.
Après déploiement, exécuter `supabase/multi_company_v1_migration.sql`.
