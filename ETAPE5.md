# Étape 5 — Planning interactif & restes clairs

- Le bouton « nouvelle semaine » génère désormais une variante réelle du planning.
- Chaque déjeuner/dîner frais peut être remplacé individuellement sans refaire toute la semaine.
- Le moteur pénalise davantage les répétitions et évite les doublons rapprochés quand le catalogue le permet.
- Le mode restes est renommé explicitement : « Restes du midi » ou « Restes d'hier ».
- Les quantités de courses tiennent maintenant compte des portions supplémentaires nécessaires pour produire réellement ces restes.
- Le batch cooking continue d'inclure les déjeuners même lorsqu'un dîner est prévu en restes.
