# Star Com'Unity V1.6.14 — Parcours e-learning

- Les ressources peuvent désormais être rattachées à un parcours pédagogique et à un niveau.
- Le nom du parcours doit correspondre au nom utilisé dans le jeu/quiz associé.
- Les ressources sont ordonnées par parcours puis niveau côté utilisateur.
- Les cartes affichent le parcours et le niveau, avec un accès vers les jeux pour passer le quiz.
- Les mécaniques de jeux existantes, feedbacks, sources, scoring et verrouillage séquentiel sont conservés.
- Migration à exécuter : `supabase/migrations/20261014193000_learning_resources_paths.sql`.
