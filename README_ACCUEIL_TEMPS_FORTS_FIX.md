# Correctif accueil – Temps forts

Le bloc d'accueil affiche désormais :

- en priorité, une animation actuellement ouverte ;
- sinon, la prochaine animation programmée, même si sa date de début n'est pas encore atteinte ;
- le libellé « Prochainement » et sa date de disponibilité pour une animation future ;
- un accès direct à la rubrique Temps forts.

Aucune migration Supabase supplémentaire n'est nécessaire.
