# Correctif colonne Anniversaires

- Les types `anniversary`, `birthday` et `anniversaire` sont normalisés.
- Les anniversaires créés manuellement sont affichés dans « Anniversaires du mois ».
- Ils sont retirés du « Fil des célébrations ».
- Le message « Aucun anniversaire ce mois-ci » ne s'affiche plus lorsqu'un anniversaire manuel existe.
- Aucune migration SQL n'est nécessaire.
