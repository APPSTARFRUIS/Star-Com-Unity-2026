# V1.4.4 — PDF, messages et classement

Correctifs intégrés sur la base V1.4.3 validée :

- Messages : séparateurs de date dans les conversations (Aujourd’hui / Hier / date complète).
- Messages : suppression des boutons téléphone et visio inactifs.
- Classements : suppression de l’onglet « Ce mois » et de son calcul redondant.
- Newsletter PDF : chaque article démarre sur une page dédiée, mise en page A4 resserrée et protections anti-chevauchement renforcées.
- Organigramme PDF : affichage initial en mode page unique, zones basses sécurisées, cartes services compactées pour éviter le chevauchement avec le pied de page.

Aucune logique métier Supabase, audiences, sondages, notifications ou documents n’a été modifiée.
